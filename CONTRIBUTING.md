# Contributing to Java Full-Stack Interview Preparation Platform

Thank you for considering contributing to this project! 🎉

## How to Contribute

### 1. Add Interview Questions

The easiest way to contribute is by adding more interview questions!

**Steps:**
1. Fork the repository
2. Edit `src/data/interviewData.json`
3. Add your question following this format:

```json
{
  "id": 999,
  "question": "Your question here?",
  "answer": "Detailed answer with examples\n\n### Code Example\n```java\n// Your code\n```\n\n**Key Points:**\n- Point 1\n- Point 2",
  "difficulty": "Easy|Medium|Hard",
  "tags": ["relevant", "tags"]
}
```

4. Submit a pull request

### 2. Improve Features

- Enhance AI validation algorithm
- Add new study tools
- Improve UI/UX
- Fix bugs

### 3. Report Issues

Found a bug? [Open an issue](https://github.com/Divahar2507/Preperation_guide/issues)

## Development Setup

```bash
git clone https://github.com/Divahar2507/Preperation_guide.git
cd Preperation_guide
npm install
npm run dev
```

## Pull Request Process

1. Update README.md if needed
2. Test your changes locally
3. Follow existing code style
4. Write clear commit messages
5. Submit PR with description

## Code of Conduct

- Be respectful
- Be collaborative
- Be constructive
